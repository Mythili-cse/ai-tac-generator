Compiler Pipeline Capabilities

LEXICAL ANALYSIS

Breaks the input expression into a stream of typed tokens (identifiers, operators, parentheses) with category tracking.

SYNTAX & PRECEDENCE

Checks AST grammar rules and enforces strict operator precedence (parentheses () over * and /, then + and -).

THREE-ADDRESS CODE

Converts complex nested expressions into intermediate instructions using sequential temporary variables (t1, t2, ...).

AI EXPLANATION

Uses an optional LLM layer to explain intermediate code evaluation steps, register allocation, and optimization logic.

About This Project

Problem Statement

Manual generation of Three-Address Code for complex expressions can be tedious and error-prone during compiler intermediate passes.

Project Objective

Automate intermediate code generation while demonstrating lexical analysis, syntax analysis, precedence handling and TAC generation.
